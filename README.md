# Nomad & Consul: Single-Node Infrastructure Setup

## Project Overview

This project demonstrates the deployment and integration of HashiCorp Nomad and Consul on a single Linux machine.

The objective is to configure Nomad for workload orchestration and Consul for service discovery and configuration management.

## Objectives

- Install and configure HashiCorp Nomad in single-node mode.
- Configure Nomad as both server and client.
- Install and configure HashiCorp Consul.
- Integrate Nomad with Consul.
- Verify service communication.
- Access both web UIs.
- Deploy and test a sample workload.

## Technology Stack

- HashiCorp Nomad
- HashiCorp Consul
- Linux (Ubuntu)
- Docker (if required)
- Git & GitHub

## Expected Architecture

A single Linux machine running:

- Nomad Server
- Nomad Client
- Consul Agent
